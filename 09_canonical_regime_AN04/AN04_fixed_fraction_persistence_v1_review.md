# OP-C1 review · refuted

**Proved.** For each ratio in the RMS box and every finite positive scale and offset above the resident, each fixed interior rank eventually stays strictly below the gate. This holds in any saturated, zero-weak-mass characteristic evolution from the unclamped normalized RMS join. More strongly, each fixed interior input tends to minus infinity. The instantaneous inactive mass at any finite gate tends to zero. The positive-survival parameter set is empty and has empty relative boundary. See `an04ffpv1:return` and `an04ffpv1:drift`.

**Refuted.** A positive time-uniform continuously inactive fraction anywhere in that domain. The GOE initial threshold still separates the two directions of initial motion. It does not separate perpetual survivors from returners.

**Approaches.** The aligned wedge fails on its diagonal already at entry. The negative proof uses the tail above a moving receiver. A gate-only computation would leave open the possibility that an interior rank never comes down to the gate. The tail reaches an input of order exp(λt/2) with an inverse-linear lower mass, whereas every fixed rank has a strictly smaller exponential ceiling. The resulting negative velocity holds throughout the exterior, including its boundary. The displacement and mass estimate for the protected set is re-proved before using its first moment.

**Handoff.** No remaining inequality for the stated problem. Keep IMP's finite-horizon lower bound. Extension to positive weak mass requires new coupled estimates, especially when the weak seed and the observation time vary together. This proof does not set a time scale for erosion at finite noise.
